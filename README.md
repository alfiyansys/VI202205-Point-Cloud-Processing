# Point Cloud Processing

Segmentasi bidang dari data LiDAR sintetis menggunakan RANSAC iteratif dan Region Growing.

## Cara Menjalankan

```bash
./run.sh
```

Script akan membuat virtual environment, menginstall dependencies, dan membuka notebook secara otomatis.

## Laporan

Tersedia di `report.pdf` (git ignored). Source code laporan ada di `report.md`, dapat di-generate ulang ke PDF dengan:

```bash
./gen_report.sh
```
